# Field from Above

Use this skill when the user asks Hermes to inspect a farm field from satellite
data, compare crop vigour, look at a Polish parcel, or check terrain context.

Choose `field_from_above_parcel` when the user gives a full Polish parcel ID.
Choose `field_from_above_point` when the user gives latitude/longitude and a
radius, including outside Poland. Explain that terrain is explicitly
unavailable outside the Poland NMT coverage and must never be paraphrased as
"flat".

Present the scene date, cloud information, NDRE measurement, terrain status and
PNG path. Keep the disclaimer: this is not a soil test and not fertiliser or
plant-protection advice. Do not invent values when a service failed.
